Als App installieren

Open BOS Drohnen lässt sich wie eine App auf den Startbildschirm legen: eigenes Symbol, Vollbild ohne Adressleiste, schneller Start. Es wird nichts aus einem App-Store geladen.

Die App ist auf diesem Gerät bereits installiert.

iPhone und iPad

  1. Seite in Safari öffnen (in neueren iOS-Versionen auch Chrome oder Edge).
  2. Auf Teilen tippen {{ icon("share", 16) }} – unten in der Leiste bzw. oben rechts auf dem iPad.
  3. „Zum Home-Bildschirm“ wählen {{ icon("plus-square", 16) }}; eventuell erst nach unten scrollen.
  4. Mit „Hinzufügen“ bestätigen.

Wurde der Link in einer anderen App geöffnet (z. B. Messenger oder E-Mail), zuerst „In Safari öffnen“ wählen.

Android

  1. Seite in Chrome, Edge oder Samsung Internet öffnen.
  2. Das Menü {{ icon("dots", 16) }} oben rechts öffnen.
  3. „App installieren“ bzw. „Zum Startbildschirm hinzufügen“ wählen und bestätigen.

Computer

In Chrome oder Edge auf das Installieren-Symbol rechts in der Adressleiste klicken oder im Menü „App installieren“ wählen.

Die Anmeldung bleibt wie im Browser erhalten. Nach einem Update lädt die App die neue Version beim nächsten Öffnen.
