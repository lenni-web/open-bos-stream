Kurzanleitung: Server in DJI Pilot 2 eintragen
  1. Fernsteuerung mit dem Internet verbinden (WLAN, Hotspot oder LTE).
  2. DJI Pilot 2 öffnen und auf der Startseite „Cloud Service“ (Cloud-Dienste) antippen.
  3. „Open Platforms“ (offene Plattformen) wählen.
  4. Diese Adresse eintragen und „Connect“ antippen: https://<domain>/dji
  5. Mit dem eigenen Open-BOS-Konto anmelden (Drohnenteam oder höher) und auf „Verbunden“ warten.
  6. Drohne einschalten. {% if can.admin %}Neue Geräte erscheinen unten; dort benennen und einer Wehr zuordnen.{% else %}Neue Geräte benennt ein Admin und ordnet sie der Wehr zu; erst dann erscheinen sie hier.{% endif %}

Die Bezeichnungen können je nach Version von Pilot 2 abweichen. Das gilt nur für Enterprise-Drohnen (z. B. Mavic 3E/3T), nicht für DJI Fly.
